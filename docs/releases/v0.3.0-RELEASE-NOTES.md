# ExamPrep Engine v0.3.0 — Proposed GitHub Release Notes

**State:** Prepared for release; **not published or deployed**. Source PR: [#77](https://github.com/Yenuka2012/examprep-engine/pull/77). Protected production main remains on v0.2.1 until pre-upgrade backup and physical iPhone acceptance.

## New — M1.1
- Local certification profiles with stable identifiers, display names and providers.
- Versioned syllabi including domain percentage weights, optional objectives and HTTPS provenance URLs.
- Draft revision tracking with cross-tab stale-write rejection; published syllabus versions cannot be edited through the catalog UI.
- Responsive Certification management navigation with existing local question-bank coverage by matching certification and syllabus version.
- Additive IndexedDB schema v3 with exam banks, attempts and active exam state preserved.
- AES-256-GCM encrypted whole-profile and individual-bank exports containing certification and syllabus data, with atomic merge-only restore.

## Data compatibility and security
- New exports use **logical backup_version 2** (mandatory `certifications` and `syllabi` arrays) inside the unchanged encrypted envelope `examprep-encrypted-backup-v1`.
- Existing logical v1 encrypted backups and explicitly approved plaintext v1 imports remain supported; logical v1 containing catalog data, unencrypted v2, malformed future fields and conflict imports are refused.
- The previously deployed v0.2.1 app refuses logical backup v2 rather than silently discarding new catalog data.
- **Important:** Dexie v3 corresponds to IndexedDB native schema version 30. A simple static rollback to v0.2.1 (Dexie v2 / version 20) will not read an upgraded browser database. Use a v3-compatible emergency fix and encrypted pre-upgrade backup; **never clear browser data as a workaround**.
- Data in the browser's IndexedDB remains plaintext at rest, scoped to the user's browser profile; no cloud sync or remote account authentication.
- A syllabus entered by a user is reference metadata, not an independently verified vendor-approved syllabus or pass-score rule.

## Validation gates (must be rechecked on the final SHA)
- npm ci, `npm audit --audit-level=high`, TypeScript, unit tests, production build.
- Playwright Chromium, WebKit, mobile WebKit: certification creation and publication, indexedDB migration and rollback safety, encrypted recovery, cross-tab stale edits and regression tests.
- CodeQL JavaScript/TypeScript and GitHub Actions, SBOM and SHA-256 site asset hashes.
- Owner acceptance on physical iPhone Safari, backup restore in a separate browser profile, offline/PWA upgrade and deployment smoke test after protected merge.

## Known limitations / remaining issues
- Offline/PWA readiness must be verified on an actual installed release. A Vite preview's offline-ready banner is not a full offline upgrade test.
- Developer dependency advisories: two low and four moderate as observed on 6 Nov 2026; no high/critical vulnerabilities were reported by `npm audit --audit-level=high`. Track upstream Workbox/PWA supply chain remediation without applying breaking `npm audit fix --force`.
- Historical intermittent WebKit export-test timeout: [#76](https://github.com/Yenuka2012/examprep-engine/issues/76).
- Physical iOS acceptance: [#49](https://github.com/Yenuka2012/examprep-engine/issues/49).
- Backup version and compatible rollback assurance: [#78](https://github.com/Yenuka2012/examprep-engine/issues/78).
- Does not yet implement official exam blueprints (#59), immutable question-bank revisioning (#34), or adaptive practice.
