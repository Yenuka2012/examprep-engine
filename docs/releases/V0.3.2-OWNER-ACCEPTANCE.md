## Clean-profile encrypted-backup acceptance sequence

1. In the current real profile, first verify whether an unfinished exam
   exists. If so, complete it safely and confirm the result is durable.
2. Check certification, syllabus, question-bank and attempt counts. Record
   counts only. Do not manually export plaintext records.
3. Use the existing full-profile **encrypted** backup export with a unique,
   high-entropy passphrase retained in a password manager. Protect the file.
4. Open a **separate clean browser profile** with no ExamPrep records.
   Open the same official production URL there, then restore the backup.
   Do not restore into the original profile to test recovery.
5. Verify every count, catalog metadata, question bank and representative
   frozen attempt result. Do not share protected answer keys, questions,
   passphrases or the backup file in acceptance comments.
6. Record PASS only if all comparisons match and the original browser
   remains available and unchanged; otherwise record FAIL and stop
   before any encrypted-vault cutover.
