# CI hotfix — P0 GitHub Pages deployment unblock (v0.3.0)

**Tracking:** [#79](https://github.com/Yenuka2012/examprep-engine/issues/79). **Scope:** GitHub Actions browser runner provisioning only; no runtime application, dependency lockfile or IndexedDB schema change.

## Incident and evidence

After the protected M1.1 PR #77 squash merge to `main` at `68c78e65e664e01a3e9b1f7d02337b9494d57b87`, [integrated production run 42185934437](https://github.com/Yenuka2012/examprep-engine/actions/runs/42185934437) failed to deploy because the `browser-tests` job reached its 40-minute limit. Browser dependencies were downloaded from `azure.archive.ubuntu.com` at severely degraded throughput during `npx playwright install --with-deps chromium webkit`. The browser suite ran only at the end and **37/37 tests passed**, but the job was classified as cancelled; `deploy` was skipped. The [independent browser run 42185934489](https://github.com/Yenuka2012/examprep-engine/actions/runs/42185934489) hit its own 30-minute cancellation while downloading apt packages.

## Hotfix

Both `.github/workflows/deploy.yml` and `.github/workflows/e2e.yml` use the official version-matched Playwright image:

```yaml
container:
  image: mcr.microsoft.com/playwright:v1.64.1-noble@sha256:2f05f8a734509a7b3f26a912639488ee08f58a7b292d14d62271bcff9038768f
  options: --user 1001
```

The immutable manifest-index digest is independently listed at [Microsoft Artifact Registry](https://mcr.microsoft.com/en-us/artifact/mar/playwright/tag/v1.64.1-noble). The image provides Chromium, WebKit and their OS libraries; project npm dependencies are still installed using `npm ci --no-fund` and tested with `npm run test:e2e`. The exact Playwright package version and browser installation directory are verified before testing. Node 24 is still provided through pinned `actions/setup-node`. The image is limited to test jobs running project-controlled synthetic pages; no untrusted browsing. The documented non-root user (1001) is selected, subject to CI runtime compatibility.

## Security and release gates preserved

- Required check IDs are unchanged: `verify`, `browser-tests`, `codeql-gate (actions)`, `codeql-gate (javascript-typescript)`.
- The independent job retains its unique name `browser-e2e-independent` to avoid ambiguous required checks.
- No test skips, CodeQL bypasses, branch-protection changes or direct `main` pushes.
- Merge via protected PR only after all current-head checks succeed; then the same-`main`-SHA deploy workflow must succeed end to end.
- Confirm live Pages UI reports `v0.3.0`, with data migration and encrypted restore smoke verification. Do not redeploy old v0.2.1 against migrated IndexedDB.

## Follow-up

Use CI logs to verify container startup duration, deterministic setup, unit checks, browser assertions, artifacts and deployment status. Monitor Microsoft image updates and future Playwright version changes; when upgrading `@playwright/test` update both image tag/digest and version assertion together.
