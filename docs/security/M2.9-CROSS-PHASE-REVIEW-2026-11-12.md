## 4. Security strengths supported by checked code

- AES-256-GCM authenticated records using bound record identity as AAD; per-record random nonce.
- 600,000-iteration PBKDF2-SHA256 wrapped DEK protected separately with master and recovery secrets; DEK reference removed on owner lock. This is **not** a replacement for a strong passphrase or server authentication.
- Explicit owner Web Locks and short IndexedDB compare-and-swap for revisions, no plaintext source imports in encrypted-only dependency graph.
- Crash-tolerant encrypted exam submission with stable attempt IDs; immutable attempt and syllabus snapshots.
- Converted backup authenticates all original logical-v2 records and provenance using independent credentials before writing only into a verified empty vault.
- Worker static-only precache, no runtime caching of answers/JSON, no forced skipWaiting/clientsClaim, restrictive dedicated HTTPS staging origin.
- Pinned GitHub Actions versions, CodeQL scans, source/build integrity evidence and browser CI including historical pre-lock source bundle.
